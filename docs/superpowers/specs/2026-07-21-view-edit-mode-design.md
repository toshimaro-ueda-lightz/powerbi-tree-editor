# 閲覧 / 編集モードの切替UI（issue #8）設計

- Issue: https://github.com/toshimaro-ueda-lightz/powerbi-tree-editor/issues/8
- 正本: 画面設計書（MVP）§3, §4.2, §11 / MVP設計・再開ガイド
- 日付: 2026-07-21

## 目的

ツリーを「見るだけ」の状態と「編集する」状態を分ける。編集ボタン押下時点の状態を担保することで、**破棄**が意味を持つようにする。画面遷移は増やさず、SCR-01 内のモードフラグとして実装する（正本 §3）。

## 確定した決定事項

- **基準日は対象外。** UI に基準日セレクトは存在しない（部署・年度のみ）。DLG-04 は部署/年度の切替のみを対象とする。基準日は将来対応として spec / Notion に明記。
- **サーバセッションは従来どおり遅延生成。** 「編集」押下でサーバへ begin 呼び出しはしない（クライアント側のモードフラグのみ）。閲覧モードは全書き込みをブロックするため、DB の状態＝編集開始時点＝破棄の戻り先となり、「破棄で編集開始時点に戻る」は自動的に満たされる。#4 の作りをやり直さない。
- **DLG-04 は2ボタン**（破棄して切替 / キャンセル）。
- **保存 / 破棄のどちらでも閲覧モードへ戻る**（編集終了の専用ボタンは設けない）。

## 状態とデータフロー

- `App` に `mode: 'view' | 'edit'` を新設（単一の真実）。
- 読み込み時: `apiService.isDirty()` が true（リロードをまたいでセッションが残存）なら `edit`、そうでなければ `view` で開始。閲覧モードの裏に未保存セッションが隠れる事故を防ぐ。
- 編集に入る = `setMode('edit')`（サーバ呼び出しなし）。
- 編集を抜ける（保存 or 破棄）= `setMode('view')`。

## モードの境界（正本の操作境界に対応）

閲覧モードでも残す（閲覧の道具）:
- 部署 / 年度セレクト
- 検索、階層フィルター、担当者フィルター（Sidebar は不変）
- ズーム、ミニマップ、枝の折りたたみ、全体表示、選択ノードへ移動
- 詳細パネル（表示のみ。重みの値・計算根拠・進捗の値は読める）

編集モードで現れる（編集操作）:
- 詳細パネルの入力欄（名称 / サブタイトル / 担当者 / 進捗 / 可能面積）と「基本情報を保存」
- 子施策追加（＋）、重み編集（PNL-02 を開くボタン）、ツリーから外す
- 保存 / 破棄ボタン、未保存マーク

## コンポーネント変更

### Header.tsx
- 新 props: `mode: 'view' | 'edit'`, `onEnterEdit: () => void`。
- 閲覧: 部署/年度 ＋ **編集** ボタンのみ。保存/破棄/保存状態は非表示。
- 編集: 部署/年度 ＋ 保存状態 ＋ **保存**（未保存時のみ有効） ＋ **破棄**。
  - 破棄は編集モード中は常に有効。未保存があれば確認→ `onDiscard`、変更がなければ確認なしで `onDiscard`（＝閲覧へ戻すだけ）。
  - 保存は `onSave`（保存後に閲覧へ戻す）。

### EditPanel.tsx
- 新 prop: `readOnly: boolean`（= `mode === 'view'`）。
- `readOnly` のとき: 入力欄（名称/サブタイトル/担当者/進捗/可能面積）を表示のみにし、「基本情報を保存」「重み編集」「ツリーから外す」ボタンを隠す。値（重み %、進捗 %、面積、計算根拠）は読める。
- `readOnly` でないとき: 現状どおり（内部の階層別 `editableBasic` ロジックはそのまま）。
- 実装方針: 進捗は readOnly のとき range/number ではなく計算値と同じ表示に、面積は input ではなくテキスト表示に。

### TreeCanvas.tsx
- 新 prop: `editable: boolean`（= `mode === 'edit'`）。
- カードデータ計算箇所で `canAddChild = editable && <既存条件>`, `canDetach = editable && <既存条件>`。閲覧モードでは ＋ と linkage解除 が描画されない。選択・折りたたみ・ズーム・ミニマップは不変。

### DLG-04（新コンポーネント ViewEditDialogs か Header 近傍に）
- 既存 `Modal` を利用した2ボタンダイアログ。
- 発火条件: `mode === 'edit'` かつ `isDirty()` で、部署 or 年度を変更しようとしたとき。
- App 側で「保留中の切替（pending department/year）」を state に持ち、DLG-04 表示中はセレクトの見た目を元の値に戻す。
- 破棄して切替: `discard()` → 保留していた部署/年度を適用 → `mode='view'`。
- キャンセル: 保留を破棄（何もしない）。
- 閲覧モード時、または編集モードでも未保存なしなら即時切替（ダイアログなし）。

### App.tsx
- `mode` state を持ち、Header / EditPanel / TreeCanvas に渡す。
- `handleChangeDepartment` / `handleChangeFiscalYear` をガード: 編集中かつ未保存なら DLG-04 を出す（pending に退避）、それ以外は即時。
- `handleEnterEdit`: `setMode('edit')`。
- `handleSave` / `handleDiscard` の末尾で `setMode('view')`。
- 初回 mount で `isDirty()` を見てモード初期値を決定（apiService の version 購読で再評価）。
